# Калькулятор мотивации таргетолога (ВК)

Отдельный репозиторий: **не** часть Second Brain. Веб-калькулятор по правилам мотивации с 01.03.2026 — все формулы зашиты в TypeScript (как лист Excel), без «думания» AI.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm test         # проверка формул на примерах из PDF
npm run build
```

## Что вводится руками

- Проекты и **несколько KPI/воронок** на проект
- **KPI план** (₽), **факт бюджета** и **лиды** за 1–14 и 15–31
- **Открут прошлого месяца** по проекту (для прироста)
- Флаг **«Не в приросте»** для новых/ушедших/запусков

## Что считает код автоматически

| Показатель | Формула |
|------------|---------|
| Факт CPL | `бюджет / лиды` |
| % от KPI | `(факт CPL / KPI план) × 100` |
| Сводный KPI за половину | `Σ (% от KPI × вес)`, вес = доля бюджета линии |
| Коэф. за лид | пороги в `src/config/motivationRules.json` |
| Прирост | `Σ открут M (пересечение) / Σ открут M−1 × 100` |
| ЗП | `H1×коэф₁ + H2×коэф₂ + месяц×коэф_прирост`, max **350 000 ₽** |

Исходники формул: `src/lib/motivation/calculate.ts`  
Тесты на PDF-примеры: `tests/motivation.examples.test.ts`
